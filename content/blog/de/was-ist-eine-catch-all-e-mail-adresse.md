Eine Catch-all-E-Mail-Adresse ist eine Adresse auf einer Domain, die so eingerichtet ist, dass sie Post für jeden denkbaren Namen annimmt, ob ein echtes Postfach dahintersteht oder nicht. Wenn Sie gerade in einem Verifizierungsbericht eine Adresse mit der Markierung Catch-all gesehen und "was ist eine Catch-all-E-Mail" gesucht haben, lautet die Kurzfassung: Die Markierung beschreibt die Domain, nicht die Person. Die Domain nimmt alles an. Eine Nachricht an vertrieb@, ein falsch getippter Name oder ein Mitarbeiter, der vor Jahren gegangen ist, landen irgendwo, statt abgelehnt zu werden.

Diese eine Designentscheidung ist der Grund, warum Catch-all-Adressen schwierig zu handhaben sind, und es lohnt sich, sie zu verstehen, bevor Sie entscheiden, was Sie mit denen auf Ihrer Liste tun.

## Wo Ihnen die Markierung meist begegnet

Die meisten treffen an einer von zwei Stellen auf den Begriff. Die erste ist ein Verifizierungsexport, in dem eine Zeile neben einer ganz gewöhnlich aussehenden Adresse als Catch-all oder Accept-all markiert ist. Die zweite ist ein Versandtool, das bei einer Adresse anhält und Sie entscheiden lässt, weil es sie nicht sauber einordnen kann.

In beiden Fällen verrät die Adresse selbst nichts. Eine Catch-all-Domain kann einem Großkonzern oder einer Zwei-Personen-Agentur gehören, und der Name vor dem At-Zeichen sieht aus wie jeder andere. Sie wissen nur deshalb, dass Sie es mit einer zu tun haben, weil ein Tool diese Markierung setzt, und deshalb überrascht der Begriff viele beim ersten Mal.

## Warum eine Firma ihre ganze Domain alles annehmen lässt

Die meisten Catch-all-Domains sind nicht das Ergebnis von etwas Ungewöhnlichem. Sie werden absichtlich so eingerichtet, aus Gründen, die für die Betreiber des Mailservers Sinn ergeben.

Gemeinsame Abteilungsaliase sind der häufigste Grund. Adressen wie info@, karriere@ und rechnung@ gehören nicht zu einer einzelnen Person, und mit einer Catch-all-Einrichtung muss keine davon von Hand angelegt werden. Tippfehlertoleranz ist ein weiterer. Schreibt ein Kunde an jon statt john, stellt eine annehmende Domain die Nachricht trotzdem zu, statt sie zurückzuschicken.

Personalwechsel drängt Firmen in dieselbe Richtung. Wenn jemand geht, kommt noch monatelang Post an die alte Adresse, und sie an eine Führungskraft oder ein gemeinsames Postfach zu leiten ist einfacher, als sie abzulehnen. Fusionen und Übernahmen kommen hinzu, denn zwei Firmen legen oft mehrere Domains zusammen und nehmen lieber alles an, als jede Altadresse zu prüfen.

In der Praxis werden die meisten Catch-all-Domains von einem kleinen IT-Team betrieben, das entschieden hat, dass Post anzunehmen weniger Arbeit ist, als eine Liste gültiger Empfänger zu pflegen.

## Catch-all-E-Mail-Adresse und Accept-all: dieselbe Einrichtung

Sie werden beide Begriffe sehen, manchmal auf demselben Ergebnisbildschirm. Catch-all ist die ältere und häufigere Bezeichnung. Accept-all ist das, was manche Anbieter und Tools stattdessen anzeigen. Im Verhalten gibt es keinen Unterschied. Beide bedeuten, dass der empfangende Server zugestimmt hat, Post an jeden Namen der Domain anzunehmen. Sagt ein Tool Catch-all und ein anderes Accept-all, sagen beide dasselbe.

## Warum eine Catch-all-Adresse schwer zu prüfen ist

Normalerweise funktioniert die Verifizierung, indem man dem empfangenden Server eine Frage stellt. Der Verifizierer beginnt den Zustellvorgang für eine bestimmte Adresse und liest, wie der Server antwortet. Ein Server, der eine Liste echter Postfächer führt, lehnt einen Namen ab, den er nicht kennt, und diese Ablehnung ist das Signal, dass die Adresse ungültig ist.

Ein Catch-all-Server gibt dieses Signal nie. Weil er so eingestellt ist, dass er jeden Empfänger annimmt, beantwortet er einen echten Namen und einen offensichtlich falschen mit derselben Erfolgsmeldung, einem schlichten SMTP 250. Der Verifizierer hat gefragt, ob das Postfach existiert, und ein Ja bekommen, das für jeden beliebigen Namen gekommen wäre. Der übliche Test läuft also bis zum Ende und liefert nichts, womit Sie arbeiten können.

## Was ein Catch-all-Ergebnis für Ihre Liste bedeutet

Ein Catch-all-Ergebnis klärt für sich allein nichts. Es bedeutet nicht, dass die Adresse ungültig ist, und es bestätigt nicht, dass das Postfach echt ist. Es bedeutet, dass die Standardprüfung die Frage nicht beantworten konnte. Das Postfach dahinter kann einem aktiven Mitarbeiter gehören oder seit Jahren tot sein, und die Markierung allein kann beides nicht trennen.

Deshalb legen Tools Catch-all-Adressen unter einem vorsichtigen Status ab, oft Riskant oder Catch-All, statt gültig oder ungültig. Auf einer B2B-Liste ist der Anteil selten klein. Wer die ganze Gruppe als Müll behandelt, entfernt still echte Menschen, und wer sie als sicher behandelt, lädt Bounces ein.

## Wie oft Sie darauf stoßen

Sie sind kein Randfall. Auf einer typischen B2B-Liste liegt eine beachtliche Minderheit der Adressen auf Catch-all-Domains, und der Anteil steigt, je mehr Ihrer Kontakte in mittleren und größeren Unternehmen arbeiten, wo gemeinsame Aliase und verwaltete Post die Regel sind. Die großen Freemail-Anbieter verhalten sich fast nie so, also zeigt eine Liste privater Adressen nur sehr wenige. Eine Liste geschäftlicher Adressen kann sehr viele zeigen. Diese Mischung ist der Grund, warum die Catch-all-Markierung genau auf den Listen am häufigsten auftaucht, die für Vertrieb und Outreach zählen, und warum es sich lohnt, ein paar Minuten über den Umgang damit nachzudenken, statt eine Pauschalregel anzuwenden.
