メールの最後の一言で迷う人は多くいます。「よろしくお願いいたします」でよいのか。英語のメールなら「Best」か、「Kind regards」か、「Thanks」か。

この記事では、英語のメールの結びの挨拶を中心に、それぞれに相当する日本語の表現も紹介します。紹介する調査やアンケートは、すべて英語のメールを対象にしたものです。

短く答えると、良いメールの締めは3つの部分でできています。わかりやすい結びの一文、場面に合った結びの挨拶、そして名前です。英語のメールでは、何かを依頼するなら「Thanks」で締めます。依頼でなければ、仕事のメールのほとんどには「Kind regards」か「Best regards」が合います。日本語のビジネスメールでは、どちらの場合も「よろしくお願いいたします。」が基本の結びの挨拶です。

```email
契約書にご署名のうえ、金曜日までにお送りいただけますでしょうか。

よろしくお願いいたします。
Priya
```

この記事の残りでは、その理由を調査結果とともに説明します。場面ごとに合う締め方、句読点のルール、他の言語での締め方、多くの人が嫌う結びの挨拶を取り上げます。

## メールの締めを構成する3つの部分

メールの締めは3つの部分に分かれ、それぞれ役割が違います。

1. **結びの一文**は、完結した文です。「木曜日までにご確認いただけますでしょうか」のように、次に何をしてほしいかを読み手に伝えます。
2. **結びの挨拶**は、名前の前に置く短い挨拶です。英語なら「Thanks,」や「Kind regards,」、日本語なら「よろしくお願いいたします。」です。
3. **名前と署名**は最後に置きます。初めてのメールでは、役職と会社名を加えてください。すぐに返す短い返信なら、名前だけで十分です。

署名は短くしてください。昔のインターネットのマナーのガイドである[RFC 1855](https://www.rfc-editor.org/rfc/rfc1855)は、4行以内を勧めていました。これは今でも通用します。整っていて統一された署名が必要なら、[メール署名作成ツール](/email-signature-generator)でGmail、Outlook、Apple Mail用の署名を作れます。

## 仕事のメールでよく使う英語の結びの挨拶と日本語の表現

仕事の英語のメールでよく見る結びの挨拶を、だいたい丁寧なものからくだけたものの順に並べました。2列目は、一般的な日本語の表現です。

| 結びの挨拶（英語） | 日本語の一般的な表現 | トーン | 合う場面 |
|---|---|---|---|
| Sincerely | 何卒よろしくお願い申し上げます。 | 改まった | カバーレター、正式な手紙、立場が上の人への初めての連絡 |
| Kind regards | よろしくお願いいたします。 | 丁寧、標準 | ほとんどの仕事のメール |
| Best regards | よろしくお願いいたします。 | 丁寧、標準 | ほとんどの仕事のメール |
| Regards | よろしくお願いいたします。 | 中立 | 短い仕事のメール、苦情、知らない相手 |
| Thank you | ありがとうございます。 | 丁寧 | 相手に助けてもらったとき、助けを求めるとき |
| Thanks | ありがとうございます。 | 親しみやすい | 依頼、短い返信、同僚 |
| Best | よろしくお願いします。 | 親しみやすい | 同僚や、よくやり取りする相手 |
| Best wishes | 今後ともよろしくお願いいたします。 | 温かい | 少し知っている相手、個人的な連絡や親しみのある連絡 |
| Have a great weekend | よい週末をお過ごしください。 | 温かい | 知っている相手への金曜日のメール |
| Cheers | 一般的に相当する表現はない | くだけた | よく知っている同僚。苦情では使わない |

「Sincerely」や「Kind regards」のような改まった締め方は、初めてのメールでは無難な選択です。相手がくだけた書き方になったら、こちらもトーンを緩めてかまいません。[British Councilのビジネス英語講座](https://learnenglish.britishcouncil.org/free-resources/business/english-emails/unit-4-starting-finishing-emails)で、どの程度改まって書くべきかを受講者が尋ねたとき、チームのメンバーは、一般的には改まったほうがよいと答えています。

## 英語の結びの挨拶についての調査結果

メールの締め方についての助言の多くは、意見にすぎません。いくつかの調査やアンケートは実際の数字を示しており、それらは予想以上に同じ方向を示しています。

### 「thanks」を含む結びの挨拶が最も返信を得た

2017年、[Boomerang](https://blog.boomerangapp.com/2017/01/how-to-end-an-email-email-sign-offs/)は、オンラインコミュニティのメーリングリストの35万件を超えるメールのスレッドで、結びの挨拶を調べました。そして、それぞれのメールがどのくらい返信を得たかを数えました。

| 結びの挨拶 | 返信率 |
|---|---|
| Thanks in advance | 65.7% |
| Thanks | 63.0% |
| Thank you | 57.9% |
| Cheers | 54.4% |
| Kind regards | 53.9% |
| Regards | 53.5% |
| Best regards | 52.9% |
| Best | 51.2% |
| すべてのメール | 47.5% |

何らかの感謝の言葉で締めたメールの返信率は62%で、それ以外は46%でした。ただし、限界も覚えておいてください。対象は知らない人同士のメーリングリストで、ビジネスメールではありません。この調査が示すのは関連であって、因果関係ではありません。Boomerang自身も、送信者と読み手の関係の影響は除外できなかったと述べています。

### 人が好む締め方と嫌う締め方

アンケートは別の質問をしています。返信を得られるかではなく、人が何を好むかです。

- 1,928人を対象とした[Perkboxのアンケート](https://www.perkbox.com/resources/blog/most-annoying-things-in-an-email-ranked)では、69%が「Kind regards」を最も良い結びの挨拶の1つに選び、次が46%の「Thanks」でした。最も嫌われたのは57%の「Love」で、44%は結びの挨拶がまったくないメールを嫌っていました。
- [YouGovがHuffPostのために行った調査](https://www.huffpost.com/entry/email-sign-off-poll_n_56ead0fee4b0860f99dbc472)では、米国の成人1,000人のうち62%が「Thanks」を最もよく使う結びの挨拶としていました。最も不快な締め方は結びの挨拶がないことで41%、次が「xoxo」で24%でした。
- 米国人1,005人を対象とした[Preplyのアンケート](https://preply.com/en/blog/email-greetings-and-signoffs/)では、最も好まれたのは「Thank you」（38%）と「Thanks」（30%）でした。

まとめると、傾向ははっきりしています。感謝と素直な丁寧さは好まれます。なれなれしすぎる締め方と、締めがまったくないことは嫌われます。

### 「Thanks in advance」は使ってよいか

「Thanks in advance」（前もってお礼を伝える表現で、日本語の「よろしくお願いします」に近いもの）は、情報源によって評価が分かれる唯一の結びの挨拶です。Boomerangのデータでは返信率が最も高く、Perkboxの回答者の21%が最も良いものの1つに選んでいます。しかし、Preplyの回答者で好んだのは5%だけでした。答えが「はい」だと決めつけているとして、厚かましいとする文章のガイドもあります。

Ask a ManagerのAlison Greenは、納得しやすいルールを示しています。[彼女によると](https://www.askamanager.org/2021/05/is-thanks-in-advance-rude-interviewer-kept-saying-he-liked-my-smile-and-more.html)、「thanks in advance」はたいていの場合問題ありません。印象が悪くなるのは、相手が断ってもおかしくない本当のお願いをするときだけです。その場合は「I'd be so grateful if you're able to make it work」（ご対応いただけましたら大変ありがたく存じます）のような表現のほうが合います。

## 返信が必要なメールの締め方

返事が必要な場合は、結びの一文が大部分の役割を果たします。結びの挨拶は、トーンを決めるだけです。

お願いは具体的にしてください。何が必要で、いつまでなのかを書きます。「ご意見をお聞かせください」のようなあいまいな締めでは、何をしてほしいのかを読み手が考えなければなりません。

```email
火曜日の14時から20分ほどお電話でお話しできますでしょうか。ご都合が合わない場合は、ご都合のよい日時を2つお知らせください。

よろしくお願いいたします。
Daniel
```

```email
会場の予約に必要なため、木曜日の終業時までに予算をご承認いただけますでしょうか。

よろしくお願いいたします。
Mia
```

質問を入れることは、一般的に効果があります。4,000万通を超えるメールを対象とした[Boomerangの別の分析](https://blog.boomerangapp.com/2016/02/7-tips-for-getting-more-responses-to-your-emails-with-data/)では、質問を1〜3個含むメールは、質問のないメールより返信を得る可能性が50%高くなっていました。この調査は、最後の一文に限らず、メールのどこかに質問があるかどうかを見たものです。それでも、主な質問を置く自然な場所は最後の一文です。

わかりやすい質問と、感謝を伝える結びの挨拶を組み合わせてください。上の返信率から考えると、何かを依頼する英語のメールでは「Thanks」が良い標準です。

## 場面別のメールの締め方の例

### 応募とカバーレター

改まった結びの挨拶と、フルネームを使ってください。英語のカバーレターでは、大学のキャリアセンターは今でも「Sincerely」を勧めています。たとえば[インディアナ大学のガイド](https://apps.ovpue.indiana.edu/cdc-guides/cover-letter/closing)は、採用担当者に時間を割いてもらったお礼を述べ、「Sincerely」と入力したフルネームで締めるよう書いています。日本語の応募メールでは、「何卒よろしくお願い申し上げます。」が一般的な表現です。

```email
お忙しいところ、ご検討いただきありがとうございます。チームにどのように貢献できるか、お話しする機会をいただけましたら幸いです。

何卒よろしくお願い申し上げます。
Jordan Lee
jordan.lee@example.com
```

「Sincerely」は古いとするサイトもあります。正式な手紙については、調査はその意見を裏付けていません。短いフォローアップのメールで硬く感じる場合は、「Kind regards」でもかまいません。

### 教授や先生へのメール

改まったトーンを保ち、自分が誰かわかるだけの情報を書いてください。[カンザス大学のWriting Center](https://writing.ku.edu/contacting-your-professor)は、「Thank you」「Best regards」「Sincerely」などの結びを勧めています。署名には、受講している授業を加えるとよいです。

```email
ご助言いただき、ありがとうございました。

よろしくお願いいたします。
Sam Patel
ECON 201, Section 3
```

### コールドメールと営業のアプローチ

コールドメールでどの結びの挨拶が最も効果的かについて、信頼できるデータはありません。シンプルにしてください。断りやすくする短い結びの一文を書き、その後に「Thanks」と名前を置きます。日本語のメールなら「よろしくお願いいたします。」と名前です。[営業メールのテンプレート](/blog/cold-email-templates)はすべてこの形で締めているので、実際の文脈で確認できます。

### 苦情

温かい締め方は避けてください。[Purdue OWL](https://owl.purdue.edu/owl/general_writing/personal_correspondence/personal_letters.html)は、「Best Wishes」や「Cheers」は苦情の効果を弱める可能性があると注意しています。場面に合わない親しさを感じさせるからです。「Regards」や「Thank you」なら、きっぱりとした丁寧なトーンを保てます。

### 社内メールと短い返信

チーム内では、ずっとくだけてかまいません。[Ask a Manager](https://www.askamanager.org/2019/07/do-i-really-have-to-use-formal-openings-and-closings-in-every-email.html)は、社内メールを「Thanks」や名前だけで締めるのはごく普通だと述べています。テンポの速いやり取りでは、結びの挨拶を完全に省く人も多くいます。ニュージーランドの職場のメールを対象としたある研究では、メールの締め方に影響していたのは、[役職や性別](https://doi.org/10.1111/j.1083-6101.2007.00333.x)よりも職場の文化でした。そのため、同僚のやり方に合わせてください。

### お礼のメール

お礼がメールの目的なので、お礼は結びの一文で伝え、結びの挨拶はシンプルにしてください。

```email
改めて、手続きを丁寧にご説明いただきありがとうございました。おかげで判断がずっと簡単になりました。

今後ともよろしくお願いいたします。
Elena
```

## 句読点と大文字の使い方

最初の3つのルールは、英語のメールに当てはまります。

- **結びの挨拶の後にはカンマを付け、**次の行に名前を書きます。[British Council](https://learnenglish.britishcouncil.org/free-resources/business/english-emails/unit-4-starting-finishing-emails)はこの方法で教えています。
- **大文字にするのは最初の単語だけです。**「Kind Regards,」ではなく、「Kind regards,」や「Best wishes,」と書きます。言語学者の[Larry Trask](https://www.sussex.ac.uk/informatics/punctuation/essaysandletters/letters)は、結びの挨拶で大文字にするのは最初の単語だけだと明確に述べています。
- **スタイルによっては、カンマなしでもかまいません。**英国の一部の企業は、書き出しの挨拶の後にも結びの挨拶の後にもカンマを付けない[オープンパンクチュエーション](https://en.wikipedia.org/wiki/Business_letter)を使っています。1つのスタイルを選び、常に同じものを使ってください。
- **他の言語には独自のルールがあります。**たとえば[Duden](https://www.duden.de/sprachwissen/sprachratgeber/Die-Gru%C3%9Fformel-in-Brief-und-E-Mail)によると、ドイツ語では結びの挨拶の後にカンマを一切付けません。日本語のメールでは、「よろしくお願いいたします。」のように結びの挨拶を句点で終わる一文にし、その下に名前や署名を置くのが一般的です。

## 他の言語とイギリス英語でのメールの締め方

海外の人にメールを書くときは、相手が使う締め方を使ってください。各言語の情報源にもとづく標準的な締め方は次のとおりです。

| 言語 | 改まった締め方 | くだけた締め方 |
|---|---|---|
| イギリス英語 | Yours sincerely（名前のわかる相手に）、Yours faithfully（「Dear Sir or Madam」で始めた場合） | Kind regards、Best wishes |
| アメリカ英語 | Sincerely | Best、Thanks |
| ドイツ語 | Mit freundlichen Grüßen | Freundliche Grüße、Beste Grüße |
| フランス語 | Cordialement | Bien à vous |
| 日本語 | 何卒よろしくお願い申し上げます。 | よろしくお願いします。 |

イギリスの手紙について、Traskは次のルールを示しています。名前のわかる相手には「Yours sincerely」、「Dear Sir or Madam」（ご担当者様）で始めた場合は「Yours faithfully」です。ただし、この区別はそれほど重要ではないとも書いています。ドイツ語の「Liebe Grüße」は、個人的なメッセージだけに使います。フランス語では、[Cordialement](https://www.connexionfrance.com/magazine/cordialement-amicalement-the-nuances-of-email-sign-offs-in-french/153929)がメールで最もよく使われ、「Veuillez agréer」で始まる長い定型句は正式な手紙で使います。

## 避けるべき結びの挨拶と締め方

- **「Love」と「xoxo」。**Perkboxのアンケートで、「Love」は57%で最も嫌われた結びの挨拶でした。どちらも家族や友人とのやり取りだけで使ってください。
- **初めてのメールで結びの挨拶がない。**Perkboxの回答者の44%が嫌っていました。Purdue OWLは、[少なくとも「Best,」などの結びと名前を入力する](https://owl.purdue.edu/owl/general_writing/general_writing_faqs.html)よう助言しています。
- **知らない相手への「Cheers」と「Warmly」。**Perkboxのアンケートでは、26%が「Cheers」を、31%が「Warmly」を最も悪いものの1つに選んでいます。
- **「Rgds」のような略語。**British Councilは「Rgds」をくだけた表現としているため、改まったメールでは使わないでください。
- **仕事での初めてのメールの顔文字。**3つの実験で、[顔文字を使うと送信者の能力が低く見え](https://doi.org/10.1177/1948550617720269)、温かみが増すこともありませんでした。
- **遠回しに相手を責める結びの一文。**「As per my last email」（前回のメールでお伝えしたとおり）にはPerkboxの回答者の33%が、「Please advise」（ご指示ください）には8%が不快を感じていました。

「Sent from my iPhone」（iPhoneから送信）は、評価が分かれます。Preplyのアンケートでは、51%がやめてほしいと答えています。一方、[2012年の研究](https://doi.org/10.1080/00909882.2012.712707)では、モバイルからの送信を示す署名があると、読み手が入力ミスを厳しく評価しにくくなることがわかりました。主にパソコンからメールを送るなら、オフにしてください。スマートフォンからなら、入力ミスを許してもらいやすくなることもあります。

## 結びの挨拶は常に必要？

初めての相手へのメールでは必要です。結びの挨拶がないと、多くの人はぶっきらぼうだと感じます。上のアンケートでも、最も嫌われる締め方の1つになっています。

やり取りが始まった後は、省いてもかまいません。同僚との短い返信のやり取りでは、名前だけ、または何も書かないのも普通です。結びの挨拶が好きな人ばかりでもありません。[Slateのエッセイ](https://slate.com/human-interest/2013/03/email-signoffs-end-them-forever-best-yours-regards-theyre-all-terrible.html)は、結びの挨拶を完全にやめるべきだと主張しました。それでも、テンポの速いやり取り以外では、結びの挨拶を入れてください。

## 送信する前に

どれほど良い締め方でも、届かないメールには意味がありません。新しい相手やリスト全体にメールを送る場合は、まずアドレスが使えるかを確認してください。[メールアドレスチェッカー](/email-checker)では1件のアドレスを、[メールアドレスの一括検証](/bulk-email-verifier)ではリスト全体を確認できます。そうすれば、言葉を選んだ結びの挨拶が、実在する受信トレイに届きます。

## よくある質問

### メールの最も良い締め方は何ですか？

わかりやすい結びの一文、結びの挨拶、名前で締めてください。英語のメールでは、何かを依頼するときは「Thanks」が最も効果的で、Boomerangのデータでも感謝を含む結びの挨拶が最も多く返信を得ています。その他の仕事のメールには「Kind regards」か「Best regards」が合います。日本語のビジネスメールでは「よろしくお願いいたします。」が基本です。

### ビジネスにふさわしいメールの締め方は？

次に何をするかを伝える一文で締めてください。その後に「Kind regards」「Best regards」「Thank you」などの丁寧な結びの挨拶と、フルネームと役職を書きます。カバーレターや正式な手紙では「Sincerely」を使います。日本語では「よろしくお願いいたします。」や、より改まった「何卒よろしくお願い申し上げます。」を使います。

### 「Regards」は失礼ですか？

失礼ではありません。中立的で短く、短い仕事のメールや苦情に合います。Perkboxのアンケートでは、31%が「Regards」を最も良い結びの挨拶の1つに選んでいます。迷う場合は、「Kind regards」のほうが少し温かく聞こえます。

### 「Kind regards」は大文字で書くべきですか？

大文字にするのは最初の単語だけです。「Kind regards,」と書きます。「Best regards,」や「Best wishes,」も同じです。

### 「Thanks in advance」は失礼ですか？

たいていは失礼ではありません。Boomerangの調査では返信率が最も高く、Ask a Managerもたいていの場合は問題ないとしています。相手が断りたいかもしれない本当のお願いをするときは避けてください。

### 「Sincerely」の代わりに何を使えますか？

メールでは「Kind regards」「Best regards」「Thank you」が一般的な代わりの表現です。「Sincerely」はカバーレターや正式な手紙に使ってください。

### 結びの挨拶の後にカンマを付けますか？

英語では、ほとんどのスタイルで付けます。「Thanks,」と書き、次の行に名前を書きます。英国では、カンマを省く人もいます。ドイツ語では、原則としてカンマを付けません。日本語では、カンマではなく句点で終わる一文にします。
