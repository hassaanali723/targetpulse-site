## ダブルオプトインとは？

ダブルオプトインとは、2つの段階でメールリストに人を追加する方法です。まず、その人がウェブサイトでメールアドレスを入力します。次に、そのアドレスに送られたメールのリンクをクリックします。その時点で初めて、アドレスがリストに追加されます。

オプトインとは、自分で選んで参加することです。「ダブル」とは、フォームで1回、メールで1回、合わせて2回選ぶという意味です。確認されなかったアドレスは、リストに追加されません。

## 例：マリアがパン屋のニュースレターに登録する

マリアは、近所のパン屋のウェブサイトを訪れます。毎月のニュースレターを受け取りたいと考えています。

1. 登録フォームに自分のアドレスmaria.lopez@gmail.comを入力し、「登録」をクリックします。
2. ウェブサイトに「受信トレイを確認して、メールアドレスを確定してください」というメッセージが表示されます。
3. 1分後、マリアにパン屋からメールが届きます。件名は「メールアドレスの確認をお願いします」です。
4. メールには「はい、登録します」というボタンが1つあります。
5. マリアがボタンをクリックします。「ありがとうございます。登録が完了しました」というページが開きます。
6. パン屋のメールツールがマリアをリストに追加します。クリックした日時も記録します。

では、マリアが間違えてmaria.lopez@gmial.comと入力していたとします。確認メールはマリアに届きません。マリアはクリックしないので、間違ったアドレスはリストに追加されません。

## シングルオプトインとダブルオプトインの違い

[シングルオプトイン](/glossary/single-opt-in)では、アドレスを入力するとすぐにリストに追加されます。確認の段階はありません。

| | シングルオプトイン | ダブルオプトイン |
| --- | --- | --- |
| 登録者の手順 | 1つ：フォームに入力する | 2つ：フォームに入力し、リンクをクリックする |
| リストの増え方 | 全員が追加されるので速い | 確認しない人もいるので遅い |
| 入力ミスのアドレス | リストに追加され、その後バウンスする | 追加されない |
| ボットによる偽の登録 | リストに追加される | 誰かがリンクをクリックしない限り追加されない |
| 同意の証拠 | 登録フォームだけ | 確認クリックの記録 |
| スパムトラップのリスク | 高い | 低い |

## 企業がダブルオプトインを使う理由

- **同意の証拠。**同意とは、その人がメールを受け取ることに合意したという意味です。ダブルオプトインなら、各登録者がいつ確認したかを示せます。
- **偽のアドレスや入力ミスのアドレスが減る。**メールを受け取れないアドレスは確認されないので、リストに入りません。
- **スパムトラップが減る。**[入力ミスのドメイン（タイポドメイン）](/glossary/typo-domain)のアドレスに、確認メールが1通届くことはあります。しかし誰もリンクをクリックしないので、リストには入りません。ほかの[スパムトラップ](/glossary/spam-trap)も同じです。
- **自分から行動して登録した読者。**リストにいる全員が、メールを希望することをリンクのクリックで確認しています。

## ESPでダブルオプトインを設定する方法

ESPとは、MailchimpやBrevoなど、リストにメールを送るために使うサービスです。多くのESPでは、ダブルオプトインを設定項目として用意しています。メニューの名前は違っても、手順は似ています。

1. リスト、オーディエンス、または登録フォームの設定を開きます。
2. ダブルオプトイン、または確認メールをオンにします。
3. 確認メールを編集します。「メールアドレスの確認をお願いします」のようなわかりやすい件名と、大きなボタンを1つ使います。
4. クリックした後に表示されるページを設定します。
5. 公開する前に、自分のアドレスでフォームをテストします。
6. ESPが登録者ごとに確認の日時を記録していることを確認します。

確認メールは短くします。登録したことを本人が覚えているうちに、すぐに送ります。

## ダブルオプトインとメールアドレス検証

ダブルオプトインと検証は役割が違い、組み合わせるとうまく機能します。登録時のチェック、つまり[メールアドレスチェッカー](/email-checker)と同じチェックを行うと、確認メールがバウンスする前にgmial.comのような入力ミスを見つけられます。その後、ダブルオプトインで、その人がアドレスの持ち主であり、メールを希望していることを確かめます。ダブルオプトインを使う前に集めた古いアドレスには、[メールアドレスの一括検証ツール](/bulk-email-verifier)を使います。定期的な[メールアドレス検証](/)の一環として、バウンスするアドレスを削除できます。
