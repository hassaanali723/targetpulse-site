## IP 평판이란?

인터넷의 모든 서버에는 IP 주소가 있습니다. IP 주소는 `192.0.2.10` 같은 숫자로, 서버를 식별합니다. 메일을 보내면 메일은 IP 주소가 있는 서버에서 나갑니다.

Gmail, Outlook.com, Yahoo 같은 메일 서비스 제공업체는 IP 주소마다 그 주소에서 온 메일을 추적합니다. 반송된 메일이 몇 통인지, 스팸으로 신고한 사람이 몇 명인지 셉니다. 그 IP가 [블랙리스트](/glossary/email-blacklist)에 있는지도 확인합니다. 업체는 이 기록을 바탕으로 그 IP를 얼마나 신뢰할지 정합니다. 이 신뢰 수준이 IP 평판입니다.

이메일 IP 평판이 좋으면 메일이 받은편지함에 도착하는 데 도움이 됩니다. 평판이 나쁘면 메일이 스팸함으로 가거나, 전송이 느려지거나, 거부됩니다.

## 예시: 공유 IP 하나를 쓰는 두 발신자

ESP란 Mailchimp나 SendGrid처럼 고객 대신 메일을 보내 주는 회사입니다. 한 ESP의 고객 두 곳이 같은 IP 주소 `192.0.2.10`에서 메일을 보낸다고 가정하겠습니다.

- **고객 A**는 서점입니다. 웹사이트에서 가입한 사람들에게 메일을 보냅니다. 반송되는 메일이 적고, 신고하는 사람도 적습니다.
- **고객 B**는 주소 50,000개가 담긴 리스트를 구매했습니다. 그중 수천 개가 반송됩니다. 많은 수신자가 “스팸 신고”를 누릅니다.

Gmail은 반송과 신고를 `192.0.2.10`의 기록으로 남깁니다. 그 IP의 평판이 떨어집니다. 이제 서점이 잘못한 것이 없는데도, 서점의 메일 일부가 스팸함으로 갈 수 있습니다.

ESP는 이런 일을 막으려고 합니다. 많은 ESP가 고객마다 반송률과 신고율을 지켜봅니다. 같은 IP를 쓰는 다른 고객을 보호하려고, 고객 B 같은 계정을 일시 정지합니다.

## 공유 IP와 전용 IP의 차이

| | 공유 IP | 전용 IP |
| --- | --- | --- |
| 이 IP로 보내는 사람 | 같은 ESP의 여러 고객 | 나만 |
| 평판을 좌우하는 것 | 이 IP로 보내는 모든 사람 | 내 메일만 |
| 적합한 발신자 | 중소규모 발신자 | 발송량이 일정한 대량 발신자 |
| 준비 | 바로 사용 가능 | 먼저 워밍업이 필요 |

전용 IP를 쓰면 평판을 완전히 직접 관리할 수 있습니다. 반대로 다른 사람의 좋은 메일이 나에게 도움을 주지도 않습니다. 새 전용 IP에는 기록이 없으므로, 평판을 천천히 쌓아야 합니다.

## IP 평판을 쌓는 요인과 떨어뜨리는 요인

다음은 좋은 IP 평판을 쌓아 줍니다.

- 갑자기 늘리지 않고 일정한 양의 메일을 보내는 것
- 리스트가 깨끗해서 반송률이 낮은 것
- 사람들이 원해서 받는 메일이라 스팸 신고가 적은 것

다음은 평판을 떨어뜨립니다.

- 존재하지 않는 주소에서 생기는 많은 [하드 바운스](/glossary/hard-bounce)
- [스팸 트랩](/glossary/spam-trap)으로 보내는 메일. 스팸 트랩은 나쁜 리스트를 쓰는 발신자를 잡기 위해서만 존재하는 주소입니다.
- 메일을 예상하지 못한 사람들의 스팸 신고
- Spamhaus 같은 블랙리스트 등록
- 기록이 없는 새 IP에서 보내는 대량 메일

## IP 평판을 확인하는 방법

1. 발송 IP를 찾습니다. Gmail 주소로 나에게 메일을 보내고, 메일을 연 뒤 “원본 보기”를 선택합니다. Gmail은 SPF 결과 옆에 IP 주소를 보여 줍니다. ESP에 물어봐도 알 수 있습니다.
2. MXToolbox 같은 블랙리스트 확인 도구에 IP를 입력합니다. 이 도구는 여러 공개 블랙리스트에서 IP를 한 번에 확인합니다.
3. Outlook.com의 경우 Microsoft SNDS(Smart Network Data Services)에 가입합니다. 내 IP가 Outlook.com 사용자에게 보내는 메일에 대한 데이터를 보여 줍니다.
4. Gmail의 경우 [Google Postmaster Tools](/glossary/postmaster-tools)를 사용합니다. 내 도메인이 Gmail 사용자에게 보내는 메일에 대한 데이터를 보여 줍니다.

## IP 평판을 개선하는 방법

1. 먼저 나쁜 리스트나 해킹된 계정 같은 원인을 찾아 해결합니다.
2. 반송되는 주소를 지우고, 다음 발송 전에 리스트를 검증합니다.
3. 메일을 한 번도 열지 않는 사람에게는 보내지 않습니다.
4. IP가 블랙리스트에 있다면, 원인을 해결한 뒤 삭제를 요청합니다.
5. 새 IP는 항상 천천히 시작합니다. 하루 발송량을 적게 시작하고 몇 주에 걸쳐 늘립니다. [IP 워밍업](/glossary/ip-warming)을 참고하십시오.

## IP 평판과 도메인 평판의 차이

IP 평판은 서버 주소에 붙습니다. [도메인 평판](/glossary/domain-reputation)은 example.com처럼 이메일 주소에서 @ 뒤에 오는 이름에 붙습니다. 새 ESP로 옮기면 IP는 바뀌지만 도메인은 그대로입니다. 업체는 두 가지를 모두 사용하며, 어느 한쪽에 문제가 생겨도 메일 전달에 해가 될 수 있습니다.

## IP 평판과 이메일 검증

반송과 스팸 트랩은 모두 IP 평판을 떨어뜨리며, 둘 다 리스트에 있는 나쁜 주소에서 생깁니다. [이메일 유효성 검사 도구](/email-checker)는 보내기 전에 주소가 존재하는지 받는 쪽 서버에 묻습니다. [대량 이메일 검증 도구](/bulk-email-verifier)는 리스트 전체에 같은 일을 하고, 반송될 주소를 표시합니다. [이메일 검증](/)으로 이런 주소를 지우면 내 IP에 기록되는 반송이 줄어듭니다. 일부 트랩은 실제로 작동하는 메일함이므로 검증으로 모든 스팸 트랩을 찾을 수는 없습니다. 하지만 쓰이지 않는 주소가 트랩으로 바뀌기 전에 지울 수 있습니다.
