## 도메인 평판이란?

도메인은 이메일 주소에서 @ 뒤에 오는 이름입니다. anna@example.com에서 도메인은 example.com입니다. Gmail, Outlook.com, Yahoo 같은 메일 서비스 제공업체는 도메인마다 그 도메인에서 온 메일의 기록을 보관합니다. 반송, 스팸 신고, 인증 결과를 추적합니다. 사람들이 메일에 어떻게 반응하는지도 추적합니다. 업체는 이 기록을 바탕으로 그 도메인을 얼마나 신뢰할지 정합니다. 이 신뢰 수준이 도메인 평판입니다.

업체가 각 메일을 실제 도메인과 연결할 수 있는 것은 레코드 3개 덕분입니다. [SPF](/glossary/spf), [DKIM](/glossary/dkim), [DMARC](/glossary/dmarc)는 메일이 실제로 어느 도메인에서 왔는지 증명합니다. 기업은 발송 서버를 자주 바꿀 수 있지만, 도메인은 보통 몇 년 동안 그대로 씁니다.

## 예시: 새 ESP로 옮길 때

Brightline이라는 회사는 news@brightline.com에서 뉴스레터를 보냅니다. 이 회사는 3년 동안 한 ESP를 사용했습니다. ESP란 Mailchimp나 Brevo처럼 고객 대신 메일을 보내 주는 회사입니다.

Brightline은 다른 ESP로 옮기기로 합니다. 이때 바뀌는 것은 다음과 같습니다.

1. 새 ESP는 다른 서버에서 메일을 보내므로 IP 주소가 바뀝니다. IP 주소란 인터넷에서 서버를 식별하는 번호입니다.
2. 도메인은 그대로입니다. 메일은 여전히 news@brightline.com에서 옵니다.
3. Gmail에는 새 IP 주소가 보입니다. 하지만 Gmail은 brightline.com과 그 DKIM 서명을 알아봅니다.
4. Brightline의 도메인 평판도 함께 옮겨 갑니다. 3년 동안 쌓인 기록 덕분에 메일이 계속 받은편지함에 도착합니다.

반대의 경우도 마찬가지입니다. Brightline의 도메인 평판이 나빴다면, 새 ESP로 옮겨도 해결되지 않았을 것입니다. 문제는 도메인에 그대로 남습니다.

## 도메인 평판과 IP 평판의 차이

| | 도메인 평판 | IP 평판 |
| --- | --- | --- |
| 평가 대상 | example.com 같은 발신 도메인 | 메일이 나가는 서버 주소 |
| ESP를 바꾸면 달라지는지 | 아니요 | 예 |
| 다른 발신자와 공유하는지 | 아니요, 내 도메인은 나만 씁니다 | 공유 IP에서는 공유하는 경우가 많습니다 |
| 업체가 식별하는 방법 | SPF, DKIM, DMARC의 도메인으로 | 연결하는 IP 주소로 |

업체는 두 가지를 모두 사용합니다. 나머지 절반은 [IP 평판](/glossary/ip-reputation) 페이지에서 설명합니다.

## 도메인 평판을 떨어뜨리는 요인

- **반송.** 존재하지 않는 주소로 가는 메일이 많으면, 구매했거나 한 번도 정리하지 않은 리스트로 보입니다.
- **스팸 신고.** Google의 발신자 가이드라인은 스팸 비율을 0.10% 미만으로 유지하고, 0.30%에는 절대 도달하지 않도록 하라고 안내합니다.
- **스팸 트랩.** 나쁜 리스트를 쓰는 발신자를 잡기 위해서만 존재하는 주소입니다. [스팸 트랩](/glossary/spam-trap)을 참고하십시오.
- **인증 누락.** SPF, DKIM, DMARC가 없으면 업체는 메일이 정말 내 것인지 확신할 수 없습니다.
- **갑작스러운 발송량.** 새 도메인이나 한동안 조용하던 도메인이 갑자기 메일 수천 통을 보내면, 스패머의 행동과 같아 보입니다.

## 도메인 평판을 확인하는 방법

공개된 단일 점수는 없습니다. 업체마다 내 도메인에 대해 자체적인 평가를 가지고 있습니다. 주로 다음 방법으로 확인합니다.

- **Google Postmaster Tools.** Gmail 사용자에게 보내는 메일을 위한 Google의 무료 서비스입니다. 도메인을 추가하고 DNS 레코드로 소유권을 증명합니다. DNS 레코드는 도메인의 공개 디렉터리에 있는 설정입니다. 그러면 스팸 비율과 인증 결과 같은 데이터를 보여 줍니다. [Google Postmaster Tools](/glossary/postmaster-tools)를 참고하십시오.
- **내 숫자.** 특정 업체에서 오픈율이 떨어지면, 그 업체에서 메일이 스팸함으로 가고 있다는 뜻일 수 있습니다.
- **블랙리스트 확인.** MXToolbox 같은 도구는 내 도메인이 공개 도메인 블랙리스트에 있는지 보여 줍니다.

## 도메인 평판을 보호하는 방법

1. 내 도메인으로 메일을 보내는 모든 서비스에 SPF, DKIM, DMARC를 설정합니다.
2. 대량 발송 전마다 리스트를 검증하고, 반송될 주소를 지웁니다.
3. 콜드메일은 brightline-mail.com이나 outreach.brightline.com처럼 별도의 도메인이나 서브도메인에서 보냅니다. 그러면 콜드메일과 기본 도메인 사이에 어느 정도 거리가 생깁니다. 다만 업체는 서브도메인을 기본 도메인과 연결할 수 있습니다.
4. 새 도메인은 천천히 시작합니다. 하루 발송량을 적게 시작하고 몇 주에 걸쳐 늘립니다. [이메일 워밍업](/glossary/email-warmup)을 참고하십시오.
5. 수신 거부를 쉽게 만듭니다. 그러면 사람들이 “스팸 신고”를 누르는 대신 수신을 거부합니다.

## 도메인 평판과 이메일 검증

반송은 업체가 도메인을 평가할 때 쓰는 신호 중 하나이며, 보내기 전에 직접 관리할 수 있습니다. [이메일 유효성 검사 도구](/email-checker)는 존재하지 않는 주소를 찾습니다. [대량 이메일 검증 도구](/bulk-email-verifier)는 리스트 전체에 같은 일을 해서, 캠페인이 실제 메일함으로 가게 합니다. 정기적인 [이메일 검증](/)은 오래된 주소가 재활용 스팸 트랩이 되기 전에 지워 줍니다. 다만 스팸 신고나 인증 누락은 해결하지 못하므로, 위의 다른 단계도 여전히 필요합니다.
